# Virtual Network Environment (GNS3 / EVE-NG / Simulated Devices)

This directory keeps notes, topology designs, and test scripts for simulated routers/switches.

### Role in Project:
- GNS3/EVE-NG runs virtual Cisco/Linux routers on your computer.
- Each router has an IP address and can be configured with SNMP.
- The backend communicates with these virtual routers exactly as it would with real physical routers.
- Standalone simulation scripts can also live here for quick testing when GNS3 is not running.
